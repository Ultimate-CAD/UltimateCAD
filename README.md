# UltimateCAD

Desktop parametric & direct 3D CAD workstation with integrated OpenSCAD modeling and a built-in FEM structural analysis workbench. Fork of [henmedia/layerling](https://github.com/henmedia/layerling) (fork of Sketchboard).

## Installation (Windows x64)
1. Download **Ultimate-CAD-Setup-x64.exe** from [Releases](https://github.com/Ultimate-CAD/UltimateCAD/releases/latest).
2. SHA-256: `a33d976b928619c973a46e430049eba7e8b48bb011a6c8b6de2db48bebd2e568`

## Optional External Gmsh 4.15.2 Setup
Download Gmsh 4.15.2 from [gmsh.info](https://gmsh.info/), unzip, and select `gmsh.exe` when opening the FEM Workbench.
